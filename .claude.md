# Инструкции для проекта Claudushka

## Стиль кода
Python 3.12, минимальные зависимости. См. [CLAUDE.md](CLAUDE.md) для стека и правил.

## Архитектура
Два сервиса в Docker Compose: `claudushka` (Telegram, bot.py) и `claudushka-wa` (WhatsApp webhook, whatsapp.py, порт 8080). Ключевые компоненты: [bot.py](bot.py) (основная логика ~1500 строк), [db.py](db.py) (SQLite: пользователи, история, память, чаты), [whatsapp.py](whatsapp.py) (FastAPI webhook), [allowed.json](allowed.json) (белые списки, legacy). Роли: admin, premium, referral, street, banned. Память извлекается каждые 10 сообщений (MEMORY_EXTRACT_EVERY=5, триггер на кратность 10). Поиск через Tavily, изображения через Gemini → fallback FLUX (gradio_client).

## Сборка и тестирование
Запуск: `docker compose up -d`
Нет формальных тестов; ручное тестирование через Telegram.

## Конвенции
Операции с пользователями через telegram_id. Проверки ролей на точках входа. Триггеры в группах: упоминание @bot, префикс "клод"/"claude" или ответ. Автопродвижение по рефералам. Дневные лимиты для роли street.

См. [README.md](README.md) для функций и команд.
