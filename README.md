# Клодушка

Персональный Telegram-бот на базе Claude API (Anthropic). Создан для себя и друзей.

## Что умеет

- Общение на русском, немецком и английском языках
- Веб-поиск — автоматический (бот сам решает гуглить) + `/search`
- Генерация изображений (`/imagine`) — Gemini «Nano Banana 2», единственный провайдер
- Бот сам может инициировать рисование внутри ответа (маркер `[[DRAW: ...]]`)
- Осведомлённость о текущей дате и времени (инжектируется в каждый запрос)
- Трёхуровневая память: краткосрочная (транскрипт с временными метками), среднесрочная (TTL 7 дней), долгосрочная
- Групповые чаты: мультиперсональный контекст, память для каждого участника отдельно
- Запоминает факты о собеседниках между сессиями (SQLite)
- Система ролей с реферальными ссылками
- Одобрение чатов через личку админу
- Ежедневный дайджест активности группового чата
- Обработка файлов и документов (JSON, YAML, код, txt)
- WhatsApp-бот (отдельный сервис, Meta API webhook)
- Самообновление через `/update` (git pull + docker restart)
- Чёрный юмор, без лишних фильтров (18+)

## Статус

## Команды

**Для всех:**

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы, реферальная ссылка |
| `/help` | Список команд (для admin — полный) |
| `/clear` | Очистить историю диалога |
| `/memory` | Что бот помнит о тебе |
| `/forget` | Забыть всё о тебе |
| `/id` | Показать Telegram ID и роль |
| `/version` | Версия бота |
| `/search <запрос>` | Веб-поиск (referral+) |
| `/imagine <описание>` | Генерация изображения (referral+) |

**Управление пользователями (admin):**

| Команда | Описание |
|---------|----------|
| `/users` | Все пользователи |
| `/role <id> <роль>` | Изменить роль |
| `/promote <id>` | → referral |
| `/premium <id>` | → premium |
| `/ban <id>` | Забанить |
| `/approve <id>` | Вручную допустить (set verified) |

**Управление чатами (admin):**

| Команда | Описание |
|---------|----------|
| `/chats` | Группы (статус + модель) + пользователи |
| `/pending` | Чаты на одобрение |
| `/approve_chat <id>` | Одобрить чат |
| `/reject_chat <id>` | Отклонить чат и выйти |
| `/allow_chat <id> [имя]` | Добавить чат вручную |
| `/deny_chat <id>` | Удалить чат |

**Модель per-chat (admin):**

В чате — без аргумента. Из личной переписки — с ID чата.

| Команда | Описание |
|---------|----------|
| `/haiku [chat_id]` | Haiku 4.5 — дефолт, самый дешёвый |
| `/sonnet [chat_id]` | Sonnet 4.6 |
| `/opus [chat_id]` | Opus 4.8 — самый умный, дорогой |

**Прочие админ-команды:**

| Команда | Описание |
|---------|----------|
| `/whitelist` | Показать белые списки |
| `/whitelist_on/off` | Включить/выключить белый список |
| `/captcha_on/off` | Включить/выключить капчу |
| `/captcha_unban <id>` | Разбанить после капчи |
| `/activity [0-100]` | Вероятность авто-реплаев в группе (%) |
| `/cost` | Расход токенов по моделям с ценами |
| `/review` | AI-обзор чата прямо сейчас |
| `/migrate` | Миграция JSON → SQLite |
| `/update` | git pull + рестарт контейнера |

**Реферальная система:**

Админы и премиум-пользователи получают реферальную ссылку в `/start`.
Пришедший по ссылке автоматически получает роль `referral` (с поиском, без лимитов).

## Стек

- Python 3.12
- python-telegram-bot 21.10
- Anthropic Claude API — Haiku 4.5 по умолчанию для всех чатов; Sonnet/Opus через `/sonnet` или `/opus`
- Tavily API (веб-поиск)
- Gemini Imagen API — «Nano Banana 2» (`gemini-3.1-flash-image-preview`), генерация изображений
- SQLite (пользователи, история, память, модели чатов) через `db.py`
- FastAPI + uvicorn (WhatsApp webhook, порт 8080)
- Docker Compose (два сервиса: `claudushka` + `claudushka-wa`)
- Hetzner Cloud (CX23, Nürnberg)

## Запуск

1. Скопировать `.env.example` в `.env`
2. Заполнить переменные: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `TAVILY_API_KEY`, `GEMINI_API_KEY`
3. Запустить: `docker compose up -d`
4. В Telegram: `/migrate` (если есть старые JSON-данные)
