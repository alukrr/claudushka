# Клодушка

Персональный Telegram-бот на базе Claude API (Anthropic). Создан для себя и друзей.

## Что умеет

- Общение на русском, немецком и английском языках
- Веб-поиск — автоматический (бот сам решает гуглить) + `/search`. В платном режиме — встроенный поиск Anthropic: под ответом строка источников `🔗 домен · домен`
- Когда бот ищет или рисует, он ставит реакцию на ваше сообщение (👀 — поиск, ✍ — рисование) вместо служебного текста; когда ответ или картинка готовы, реакция снимается
- Генерация изображений (`/imagine`) — переключаемый провайдер per-chat: GPT Image 2 (дефолт), Gemini «Nano Banana 2.1» или «Nano Banana Pro», GPT Image 2.5 Flare или Sunburst (`/banana`, `/bananapro`, `/gptimage`, `/flare`, `/sunburst`, `/imagemodels`)
- Бот сам может инициировать рисование внутри ответа (маркер `[[DRAW: ...]]`)
- Присылает код и текст файлом целиком по просьбе («пришли файлом», «весь модуль») — отступы не ломаются, Telegram не режет (маркер `[[FILE: имя]]`)
- Режим разработчика в платной личке (`/dev`): код файлами (в т.ч. альбомом), рабочая папка `/ws`, правки приходят файлом целиком, скриншоты ошибок; без персоны, памяти и рисования
- Пять режимов характера на чат: классическая, деловая, язвительная, игривая, бабушка (`/classic /business /toxic /flirt /granny`, список — `/personas`). В бесплатном режиме характер каждый день случайный; выбирать — в платном (в группе — админам чата и бота)
- Осведомлённость о текущей дате и времени (инжектируется в каждый запрос)
- Трёхуровневая память: краткосрочная (транскрипт с временными метками), среднесрочная (TTL 7 дней), долгосрочная
- Групповые чаты: мультиперсональный контекст, память для каждого участника отдельно
- Запоминает факты о собеседниках между сессиями (SQLite)
- Система ролей с реферальными ссылками
- Одобрение чатов через личку админу
- Ежедневный дайджест активности группового чата
- Обработка файлов и документов (JSON, YAML, код, txt)
- Понимает фото, голосовые и видео (в т.ч. кружочки) — в группе распознаёт пассивно, для контекста, даже если бота не звали
- WhatsApp-бот (отдельный сервис, Meta API webhook)
- Самообновление через `/update` (git pull + docker restart)
- Переживает сбои API: перегрузку сервиса (529) и рейт-лимиты повторяет сама, окончательные ошибки объясняет по-человечески — сырых traceback'ов в чате больше нет
- Чёрный юмор, без лишних фильтров (18+)

## Статус

- ✅ Личные чаты
- ✅ Групповые чаты (по триггеру: Клод/Клодушка/Claude/@username/reply)

## Доступ, режимы, баланс

Бот отвечает всем, кроме забаненных. Два независимых измерения:

| | Что определяет | Как получить |
|---|---|---|
| **Проверенный / непроверенный** | лимиты | пополнение от $5 (авто), `/verify` от админа |
| **Платный / бесплатный режим** | модели, картинки, ежедневный обзор | баланс > 0 (`/topup` от админа; проверенным — стартовый бонус $10 группе / $5 личке) |

**Непроверенные** (личка / группа, где не проверены ни чат, ни автор): 50 ответов в сутки в
личке, 20 на участника в группе, 20 поисков в сутки. Сверх лимита — одно сообщение в сутки,
дальше бот молчит до 00:00 (Берлин). Проверенные — без лимитов сообщений и поиска.

**Бесплатный режим** (баланс закончился): только Gemini 3.1 Flash-Lite (выбора нет), картинки только GPT Image 2 с лимитом
(личка 10 в сутки, группа 5 на участника), ежедневный обзор не отправляется. Прошлый выбор
модели/провайдера не стирается — вернётся после пополнения.
**Платный режим**: все модели (по умолчанию Gemini 3.8 Flash), картинки Nano Banana 2, GPT Image 2,
GPT Image 2.5 Flare или Sunburst без дневного лимита, ежедневный обзор на Gemini 4 Argon. Расход
списывается с баланса, `/cost` показывает баланс,
режим, траты за день/неделю и прогноз. Баланс в минус не уходит.

Админы бота — всегда проверенные и платные.

**Для всех:**

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы |
| `/help` | Список команд (для admin — полный) |
| `/clear` | Очистить историю диалога |
| `/memory` | Что бот помнит о тебе |
| `/profile` | Твой профиль в этом чате (имя, город, профессия…) — подтверждается админами раз в неделю |
| `/forget` | Забыть всё о тебе (память и профиль) |
| `/id` | Показать Telegram ID и статус |
| `/version` | Версия бота |
| `/cost` | Баланс, режим, расход. В личке — твой; в группе — для админов группы |
| `/search <запрос>` | Веб-поиск |
| `/imagine [2k] <описание>` | Генерация изображения; `2k` — высокое разрешение (Nano Banana), приходит документом без сжатия |
| `/models` | Какие модели доступны, цены, режим; ▸ = текущая |
| `/dev` | Режим разработчика (личка, платный режим): включить и статус; `/dev off` — выключить, `/dev reset` — очистить тред режима |
| `/ws` | Файлы режима разработчика: список; `/ws get <имя>`, `/ws rm <имя>`, `/ws clear yes` |
| `/lite` | Gemini 3.1 Flash-Lite (единственная модель бесплатного режима) |
| `/flash` `/argon` | Gemini 3.8 Flash (дефолт платного режима) / Gemini 4 Argon (платный режим) |
| `/imagemodels` | Какой провайдер картинок сейчас у чата |
| `/banana` | Рисовать через Nano Banana 2.1 (платный режим) |
| `/bananapro` | Рисовать через Nano Banana Pro (платный режим, сразу 2K; в группе — только админы чата и бота) |
| `/gptimage` | Рисовать через GPT Image 2 (единственный в бесплатном режиме) |
| `/flare` (`/gpt25f`) | Рисовать через GPT Image 2.5 Flare (платный режим) |
| `/sunburst` (`/gpt25s`) | Рисовать через GPT Image 2.5 Sunburst (платный режим) |

**Управление группой (доступно админам конкретной группы, не только боту-админу):**

`/ratelimit` ограничивает, как часто конкретный участник группы может обращаться
к Клодушке — включая `/search` и `/imagine`, не только обычные сообщения.
При превышении бот просто молчит, без сообщения об ошибке.

| Использование | Действие |
|---------|----------|
| `/ratelimit` | Показать текущие лимиты в этом чате |
| Ответом на сообщение (без аргументов) | Показать текущий лимит этого участника |
| Ответом на сообщение: `/ratelimit <N>` | Не чаще раза в N минут для автора реплики |
| Ответом на сообщение: `/ratelimit off` | Снять лимит с этого участника |
| `/ratelimit <user_id> <N\|off>` | То же самое по ID, без ответа на сообщение |
| `/ratelimit off` (без ответа) | Снять лимиты со всех участников чата |

`/review_on` и `/review_off` включают/выключают ежедневный авто-обзор ИМЕННО ЭТОГО чата
(рассылается раз в день по расписанию). Не путать с `/review` — тот шлёт обзор прямо
сейчас и остаётся admin-only (см. ниже).

**Баланс, проверка, баны (admin):**

| Команда | Описание |
|---------|----------|
| `/topup <chat_id> <сумма> [коммент] [force]` | Пополнить баланс чата ($); ID вне базы — только с `force`; отрицательная сумма — корректировка. От $5 суммарных пополнений чат проверяется автоматически |
| `/verify <id>` / `/unverify <id>` | Проверить / снять проверку (id с минусом — группа); `/verify` выдаёт стартовый бонус |
| `/ban <id>` / `/unban <id>` | Бан / разбан (в группе можно ответом на сообщение). Не трогает баланс и проверку; забаненная группа молчит |
| `/cost` | В личке админа — расход по всем чатам; `/cost <chat_id>` — детализация за 7 дней |
| `/users` | Все пользователи |
| `/chats` | Группы и пользователи: проверка, бан, модель, баланс |

Неизвестная группа сразу работает как непроверенная; админам приходит «меня добавили» с `/verify` и `/ban`.

**Модель per-chat:**

Без аргумента — текущий чат. Всё, кроме Lite, — в платном режиме (админу — всегда).
С `chat_id` — любой чат, только админу. Выбор постоянный, переживает рестарт; в бесплатном режиме
не применяется, но и не стирается. Перед записью бот делает пробный запрос: нерабочая модель не сохранится.

| Команда | Описание |
|---------|----------|
| `/models [chat_id]` | Список моделей и текущая модель чата |
| `/lite [chat_id]` | Gemini 3.1 Flash-Lite — $0.25/$1.50 за MTok, окно 1M (единственная модель бесплатного режима) |
| `/flash [chat_id]` | Gemini 3.8 Flash — $0.75/$3.75, окно 1M (дефолт платного режима) |
| `/argon [chat_id]` | Gemini 4 Argon — $2/$10, окно 1M (платный режим; модель дневного обзора) |

С 2026-10-28 пул не отдаёт модели Anthropic: `/haiku` `/sonnet` `/opus` `/fable` остались заглушками
(подсказка выбрать модель в `/models`). Если модель чата упала, ответ даёт GPT другого провайдера
(Lite → Luna, Flash → Terra, Argon → Sol); в `/cost` такие строки с меткой `*_fallback`.

**Провайдер картинок per-chat:**

Без аргумента — текущий чат. `/banana`, `/bananapro`, `/flare`, `/sunburst` — платный режим, `/gptimage` —
везде (в бесплатном — единственный, с дневным лимитом).
С `chat_id` — любой чат, только админу. Выбор постоянный, переживает рестарт.
В отличие от моделей — без пробного запроса перед записью (генерация картинки стоит
реальных денег и десятки секунд): ошибка провайдера всплывёт при первом рисовании.

| Команда | Описание |
|---------|----------|
| `/imagemodels [chat_id]` | Текущий провайдер картинок чата |
| `/banana [chat_id]` | Nano Banana 2.1 (~$0.034 за 1K, $0.05 за 2K) — дефолт платного режима |
| `/bananapro [chat_id]` | Nano Banana Pro (~$0.134 за 2K) — платный режим; в группе переключают админы чата и бота |
| `/gptimage [chat_id]` | GPT Image 2 (~$0.02) — через пул api.apitoken.sale, единственный в бесплатном режиме |
| `/flare [chat_id]` (`/gpt25f`) | GPT Image 2.5 Flare (~$0.02) — через пул api.apitoken.sale |
| `/sunburst [chat_id]` (`/gpt25s`) | GPT Image 2.5 Sunburst (~$0.02) — через пул api.apitoken.sale |

**Прочие админ-команды:**

| Команда | Описание |
|---------|----------|
| `/captcha_on/off` | Включить/выключить капчу |
| `/captcha_unban <id>` | Разбанить после капчи |
| `/activity [0-100]` | Вероятность авто-реплаев в группе (%) |
| `/review` | AI-обзор чата прямо сейчас: весь лог с прошлого обзора (21:00), блоки тем, как у ежедневного (на модели чата) |
| `/review_on` / `/review_off` | Вкл/выкл ежедневный авто-обзор чата (доступно и админам группы; шлётся только в платном режиме, на Gemini 4 Argon) |
| `/update` | git pull + рестарт контейнера |

## Стек

- Python 3.12
- python-telegram-bot 22.8
- Модели чата — Gemini 3.1 Flash-Lite / 3.8 Flash / 4 Argon через пул api.apitoken.sale (Anthropic Messages API-полоса `/v1/messages`, SDK `anthropic`); фолбэк — GPT-6 Luna / 6.1 Terra / 6.1 Sol (`/models`). Модели Anthropic пул не отдаёт с 2026-10-28
- Tavily API (веб-поиск в бесплатном режиме и `/search`); веб-поиск GPT (`gpt-6-luna`) — в платном режиме (`/searchmode`)
- Генерация изображений, переключаемый провайдер per-chat: Gemini «Nano Banana 2» (`gemini-3.1-flash-image-preview`, прямой Google API) или через пул api.apitoken.sale — GPT Image 2 (`gpt-image-2`), GPT Image 2.5 Flare (`openai/gpt-image-2.5-flare`) или Sunburst (`openai/gpt-image-2.5-sunburst`)
- SQLite (пользователи, история, память, модели чатов, провайдер картинок, учёт расхода и балансы) через `db.py`
- Общая обработка ошибок API в `api_errors.py` (ретраи + сообщения пользователю)
- FastAPI + uvicorn (WhatsApp webhook, порт 8080)
- Docker Compose (два сервиса: `claudushka` + `claudushka-wa`)
- Hetzner Cloud (CX23, Nürnberg)

## Запуск

1. Скопировать `.env.example` в `.env`
2. Заполнить переменные: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `TAVILY_API_KEY`, `GEMINI_API_KEY`
3. Запустить: `docker compose up -d`

Прод живёт на Hetzner, доступ по SSH через локальный алиас (`SSH_HOST`, задаётся вне репозитория). Правила для
AI-агентов (только с явного согласия владельца, сначала чтение) — в `CLAUDE.md`, раздел
«Доступ к серверу (SSH)».
