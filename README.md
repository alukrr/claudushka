# Клодушка

Персональный Telegram-бот на базе Claude API (Anthropic). Создан для себя и друзей.

## Что умеет

- Общение на русском, немецком и английском языках
- Веб-поиск (автоматический + /search)
- Запоминает факты о собеседнике между сессиями (SQLite)
- AI-капча для новых пользователей (загадки на языке собеседника)
- Система ролей с реферальными ссылками
- Одобрение чатов через личку админу

## Роли

admin - без капчи, с поиском, без лимитов, может приглашать
premium - без капчи, с поиском, без лимитов, может приглашать
referral - с капчей, с поиском, без лимитов
street - с капчей, без поиска, 10 сообщений в день
banned - заблокирован

## Стек

- Python 3.12
- python-telegram-bot 21.10
- Anthropic Claude API (Sonnet + Haiku)
- Tavily API (веб-поиск)
- SQLite
- Docker Compose
- Hetzner Cloud (CX23, Nuernberg)
