# Чек-лист стенда: ТЗ `feat/forget-confirm` (`/forget` с подтверждением, областью «этот чат», `/forget all`, «сувенирами»)

ТЗ — `docs/claude/tz-forget-confirm.md`, устройство — `docs/claude/memory.md` → «`/forget`». Места и функции `q` / `logs` — `docs/claude/staging-aliases.sh`.
Выкатка на стенд: в `~/claudushka-test` `git fetch && git checkout --detach origin/feat/forget-confirm`, затем
`docker compose -f docker-compose.test.yml up -d --force-recreate claudushka-test` (новых переменных и volume нет: каталог `data/forget-backups/`
создаётся кодом при первом стирании). **Бэкап БД стенда** перед началом.
Нужны: две тестовые группы (А — платная, Б — free: баланс 0), второй участник (не автор команды), личка с ботом, у «тестового человека» в базе
≥ 6 фактов в группе А, ≥ 3 в группе Б, ≥ 2 личных, пара полей профиля в А и в личке, личный тред. Если фактов мало — набрать через `/memory`-цикл
или вставить строки в БД стенда. Прод, dnd и `edge` не трогать. Только тестовый бот (токен стенда), токен прода не использовать.

Числа до: `q "SELECT context, chat_id, tier, COUNT(*) FROM memory WHERE user_id=<UID> GROUP BY 1,2,3"`; `q "SELECT chat_id, COUNT(*) FROM user_profile WHERE user_id=<UID> GROUP BY 1"`;
`q "SELECT COUNT(*) FROM conversations WHERE user_id=<UID>"`. Записать.
