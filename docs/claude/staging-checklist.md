из `.env.test`. Пройди пункты по порядку, для каждого — Telegram-действие → сверь с
ожидаемым результатом → при странном поведении глянь строку в логах

## ТЗ v0.10 (учёт, тарифы, доступ) — сценарии стенда

Перед прогоном: `/topup <id тестовой группы> 0.05` (или свежий чат без баланса) — так проще дойти до нуля.
Ссылки на устройство — `docs/claude/billing.md`. `sqlite3 data/claudushka.db` на сервере — для проверок таблиц.

| # | Сценарий | Ожидание |
|---|---|---|
| B1 | Сообщение боту в тестовой группе, затем `SELECT chat_id, label, kind, billed FROM usage_log ORDER BY id DESC LIMIT 10;` | Все строки (в т.ч. `should_search`, `extract_chat_memory`, `draw_translate`) с `chat_id` этой группы; **NULL — сразу доложить**, не обходить |
| B2 | `/topup <chat> 3`, затем `/topup <chat> 2` | Первый: режим платный, «не проверен»; второй: авто-проверка + бонус $10; в чат пришло «Платный режим включён…» |
| B3 | `/topup <chat> -<баланс+1>` или трата до нуля | Баланс ровно $0.00, в `chat_credits` есть `writeoff`, в чат ОДНО сообщение «Баланс закончился…», следующие ответы — Haiku |
| B4 | Free-чат: `/sonnet`, `/opus`, `/fable`, `/banana`; `/haiku`, `/gptimage`, `/models` | Первые четыре — «доступно в платном режиме»; остальные работают, `chat_models` не меняется |
| B5 | Free-личка: 10 раз «нарисуй кота», затем ещё раз; в группе — по 5 от одного участника | Лимит с временем сброса; спонтанный `[[DRAW]]` — молча без картинки и без маркера в тексте |
| B6 | Непроверенная личка: 50 ответов (можно временно снизить `UNVERIFIED_MSG_PRIVATE_PER_DAY`) | После лимита одно сообщение про сброс и `$5`/`@alukr`, дальше тишина; поиск сверх 20 — ответ без поиска |
| B7 | Непроверенная группа + проверенный пользователь (`/verify <uid>`) | Лимит 20/сутки на него НЕ действует; на обычного участника — действует |
| B8 | Вернуть баланс (B2) после B3 | Прежний выбор модели/провайдера восстановился |
| B9 | `/fable` дважды в течение 2 минут (и один раз с паузой > 2 минут) | Первый — жирное предупреждение с N; второй — переключение; после паузы — снова предупреждение; уже на Fable — просто сообщение |
| B10 | `/cost` от админа в личке / админа группы в группе / обычного юзера в личке / обычного участника в группе; `/cost <chat_id>` | Все чаты + доп. блок / только группа / только его личка / тишина; детализация только админу |
| B11 | Дневной обзор на paid-группе: временно вызвать `daily_chat_review` (или подождать 22:00 по Берлину) | Обзор на Opus (`usage_log.model='claude-opus-5'`, `label='daily_review'`, `billed=1`), ~1000–1200 знаков, последняя строка «Отключить ежедневный обзор: /review_off…» |
| B12 | `/ban <uid>` / `/ban <chat>` → сообщения, `/unban`; баланс и `/verify`-статус до/после | Бот молчит (группа — и на команды, кроме админских); баланс и проверка не изменились |
| B13 | Добавить бота в новую группу | Отвечает сразу, `allowed_chats.status='pending'`, бонуса нет (`chat_credits` пуст) |
| B14 | Миграция на копии прод-БД: `docker compose -f docker-compose.test.yml up` со снапшотом `data/` | В логе `Migration applied: billing_*`; бонусы только проверенным с активностью; `chat_models`/`chat_image_provider` без Haiku/gpt строк |
