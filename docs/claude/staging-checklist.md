# Чек-лист для стенда (ТЗ-4, этап 3)

Стенд поднят (`docs/claude/staging.md`), тестовый бот добавлен в Telegram по токену
из `.env.test`. Пройди пункты по порядку, для каждого — Telegram-действие → сверь с
ожидаемым результатом → при странном поведении глянь строку в логах
(`docker logs claudushka-test` для бота, `docker logs claudushka-wa-test` для WhatsApp).
Не обязательно останавливаться на первой проблеме — отметь все несовпадения и пришли
логи целиком (см. низ файла), решение «в прод / доработать» принимается после разбора.

## Что прислать по итогам

1. Полный вывод `docker logs claudushka-test` и `docker logs claudushka-wa-test` за
   время прогона (не только grep из п.18 — полный лог нужен для разбора неожиданностей).
2. Для каждого пункта — совпал результат с ожидаемым или нет (если нет — что увидел
   вместо этого, скриншот из Telegram при возможности).
3. Любые ошибки/трейсбеки, даже если бот в итоге как-то ответил.
