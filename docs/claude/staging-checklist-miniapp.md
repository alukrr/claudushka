# Чек-лист стенда: ТЗ `feat/miniapp` (мини-приложение настроек, v2.6.0)

ТЗ — `docs/claude/tz-miniapp.md`, дизайн — `docs/claude/miniapp.md`. Места **TG-админ / TG-участник / Сервер** и функции `q` / `logs` —
`docs/claude/staging-aliases.sh`. **Выкатка — только `--force-recreate`** (новый том `./miniapp`, сеть `edge`, переменная в `.env.test`), не `/update`:
в `~/claudushka-test` `git fetch && git checkout feat/miniapp && git pull`, в `.env.test` добавить `MINIAPP_PUBLIC_URL=https://claudushka-test.alukr.de`,
`docker compose -f docker-compose.test.yml up -d --force-recreate claudushka-test`. Юнит-тесты: `python -m pytest scripts/test_miniapp.py -q`.
Нужны: тестовая группа стенда в платном режиме (`/topup`), аккаунты **А** (админ группы в Telegram), **В** (обычный участник, писал в группе), **С** (посторонний:
не в группе), админ бота; одна свободная группа без баланса. Стек `edge`, dnd и прод не трогать.
