# Чек-лист стенда: ТЗ `feat/review-persona` (характер обзора отдельно + пометка с темами, v2.3.0)

ТЗ — `docs/claude/tz-review-persona.md`, дизайн — `docs/claude/personas.md` («Обзор, поиск, остальное»), `docs/claude/daily-review.md`.
Места **TG-админ / TG-юзер / Сервер** и функции `q` / `logs` — `docs/claude/staging-aliases.sh`. Новая таблица `chat_review_persona`
создаётся при старте (`init_db`), новых файлов и volume нет — выкатка `/update`. Юнит-тесты: `python -m pytest scripts/test_review_persona.py -q`.

| Шаг | Где | Что делаю | Ожидание |
|---|---|---|---|
| 1 | Сервер | `q "SELECT name FROM sqlite_master WHERE name='chat_review_persona'"` | Таблица есть |
| 2 | Группа, участник (не админ) | `/review_persona` | Показ: «Обзор для …: <label> (как у чата — <label>)», список ключей с ▸, формат |
| 3 | Группа, участник (не админ) | `/review_persona toxic` | Отказ «только админы чата и админы бота»; `q "SELECT * FROM chat_review_persona"` пусто |
| 4 | Группа, админ чата | `/review_persona toxic` | «характер обзора — <toxic label>»; строка в таблице; чат остаётся `classic` (`/personas`) |
| 5 | Группа | `/personas` | Есть строка «Обзор: … (отдельный). /review_persona» |
| 6 | Группа, админ | `/review_persona qqq` | Подсказка формата со списком ключей, запись не менялась |
| 7 | Личка | `/review_persona toxic` | «Обзор бывает только в групповых чатах» |
| 8 | Личка, админ бота | `/review_persona toxic <chat_id группы>` | Записано для чужого чата; не-админ с `chat_id` — отказ |
| 9 | Free-группа | не-админ бота: `/review_persona toxic`; админ бота: то же | Первому «платная функция, баланс — /cost»; второй записывает с пометкой «включится после пополнения» |
| 10 | Группа, админ бота | Насыпать ≥ 10 реплик, чат `classic`, обзор `toxic` → `/review` | Обзор в токсичной подаче при общении в `classic` |
| 11 | Группа | `/review_persona off`, снова `/review` | Подача по режиму чата; строка в таблице удалена |
| 12 | Сервер | После `/review`: `q "SELECT is_bot, length(text) len, text FROM group_messages WHERE chat_id=<id> AND is_bot=1 ORDER BY id DESC LIMIT 1"` | Текст начинается с «(обзор дня по N …», дальше «Темы обзора (…): заголовки через «; »», `len ≤ 800`, тела абзацев нет |
| 13 | Сервер | Сверить N с числом человеческих реплик окна | N = числу реплик людей, ботовые не считаются |
| 14 | Группа | Сразу ещё раз `/review` | Новый обзор НЕ пересказывает предыдущий (запись с префиксом выкинута из лога) |
| 15 | Группа | Сказать боту «ты выдумала этот обзор», reply на сообщение обзора с вопросом про конкретную тему | Модель видит темы в истории и цитату reply, не «признаётся» в выдумке (инцидент 2026-10-22) |
| 16 | Сервер | `logs 200 \| grep -i "unknown review persona"` | Пусто |
