# Чек-лист стенда: ТЗ `feat/review-topics` (дневной обзор за сутки с блоками тем, v1.10.0)

Дизайн — `docs/claude/daily-review.md` (раздел «Обзор за сутки с блоками тем»), ТЗ — `docs/claude/tz-daily-review-topics.md`.
Места **TG-админ / Сервер** и функции `q` / `logs` — `docs/claude/staging-aliases.sh`, `staging-checklist-v0.10.md` (0.2).
Чат для проверок — тестовая группа стенда (платная: баланс > 0). Лог набивается синтетикой прямо в БД стенда (шаг 1),
ждать 21:00 не нужно: `/review` идёт тем же путём (то же окно, ветки A/B), финал на модели чата.

Подготовка записей (Сервер, `q` — sqlite стенда; подставь `CHAT` — id тестовой группы, отрицательный):
```sql
-- 120 сообщений трёх людей за последние сутки, по одному в ~10 минут (сессии с паузами добавь вручную)
WITH RECURSIVE n(i) AS (SELECT 0 UNION ALL SELECT i+1 FROM n WHERE i < 119)
INSERT INTO group_messages (chat_id, user_id, sender_name, content, is_bot, timestamp)
SELECT CAST(:CHAT AS INTEGER), 1000 + i % 3, CASE i % 3 WHEN 0 THEN 'Аня' WHEN 1 THEN 'Боря' ELSE 'Вика' END,
       'тестовое сообщение ' || i || ' про ' || CASE i % 4 WHEN 0 THEN 'отпуск' WHEN 1 THEN 'работу' WHEN 2 THEN 'ремонт' ELSE 'кота' END,
       0, CAST(strftime('%s','now') AS INTEGER) - (120 - i) * 600 FROM n;
```
