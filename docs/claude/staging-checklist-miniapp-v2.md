# Чек-лист стенда: ТЗ `feat/miniapp-v2` (экран «Расходы», открытие из группы, «По месяцам» в `/cost`)

ТЗ — `docs/claude/tz-miniapp-v2.md`, дизайн — `docs/claude/miniapp.md` (разделы «Расходы», «Открытие приложения»). Места **TG-админ / TG-участник / Сервер** и функции `q` / `logs` —
`docs/claude/staging-aliases.sh`. **Выкатка — только `--force-recreate`** (меняется `.env.test`): в `~/claudushka-test` `git fetch && git checkout feat/miniapp-v2 && git pull`,
`docker compose -f docker-compose.test.yml up -d --force-recreate claudushka-test`. Юнит-тесты: `python -m pytest scripts/test_miniapp_costs.py scripts/test_miniapp.py -q`.

**Ручной шаг перед частью B (Алексей):** в @BotFather для ТЕСТОВОГО бота включить Main Mini App с URL `https://claudushka-test.alukr.de` (точный путь в меню BotFather сверить на месте),
затем в `.env.test` добавить `MINIAPP_MAIN_APP=1` и пересоздать контейнер. Для прода — то же отдельно, после стенда.

Нужны: тестовая группа стенда в платном режиме с историей расходов (хотя бы пара дней и пара месяцев в `usage_log`; недостающее можно получить `q`-вставкой строк с нужным `ts`
на стенде), аккаунты **А** (админ группы в Telegram), **У** (управляющий, `/manager add`, в Telegram не админ), **В** (обычный участник), **С** (не в группе), админ бота. Стек `edge`, dnd и прод не трогать.

| Шаг | Где | Что делаю | Ожидание |
|---|---|---|---|
| 1 | Сервер | `logs 80 \| grep -iE "miniapp\|Traceback"`; `curl -s -o /dev/null -w "%{http_code}\n" https://claudushka-test.alukr.de/api/chats/-1/costs` | «miniapp: сервер на :8090…», без Traceback; запрос без подписи — 401 |

| 3 | Группа, А | Включить `MINIAPP_MAIN_APP=1` + Main Mini App в BotFather, `--force-recreate`; `/settings` | «Настройки Клодушки:» и две кнопки: «Открыть настройки» (`t.me/<бот>?startapp=chat_n…`) и «Открыть в личке» |
| 4 | Группа, А | Нажать «Открыть настройки» **на iOS, Android, Desktop** (отдельно каждый, отметить результат) | Приложение открывается прямо в группе и СРАЗУ на экране этой группы (не на списке чатов); в `docker logs` нет 4xx на `…/settings` |

| 8 | Группа, А | Нажать «Открыть в личке» (запасной путь) | Как в v1: в личке «Настройки чата» → приложение открывается на группе |
