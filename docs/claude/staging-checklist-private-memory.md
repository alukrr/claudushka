## Подготовка (один раз)
1. `q "SELECT COUNT(*) FROM conversations WHERE user_id=<UID>"` — записать `n`. Следующая отсечка — ближайшее кратное 10 после `n`. Чтобы не ждать, перед проверкой
   можно очистить тред `/clear` в личке (счёт пойдёт заново; тогда отсечка — на 10-й строке, то есть после 5-го ответа).
2. `q "SELECT COUNT(*) FROM memory WHERE user_id=<UID> AND context='private'"` — записать (на проде такого нет; на стенде могут быть тестовые «личные факты» от проверки `/forget`).
3. `q "SELECT COUNT(*) FROM usage_log WHERE label='extract_memory'"` — записать.
