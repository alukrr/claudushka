# Чек-лист стенда: ТЗ `feat/native-search` (нативный web_search в платном режиме, v1.2.0)

Дизайн — `docs/claude/native-search.md`. Места **TG-админ / TG-юзер / Сервер**, функции `q` / `qw` / `logs` /
`cache` — `docs/claude/staging-aliases.sh`. «Платный чат» = баланс > 0 (или личный чат админа), «бесплатный» = баланс 0.

```bash
# Поиски и диалоги последних реплик
search() { q "SELECT id, kind, model, label, cost_usd FROM usage_log WHERE kind='search' ORDER BY id DESC LIMIT ${1:-6}"; }
```
