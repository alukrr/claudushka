# Чек-лист стенда: ТЗ `feat/broadcast` (рассылка `/broadcast`)

ТЗ — `docs/claude/tz-broadcast.md`, устройство — `docs/claude/broadcast.md`. Места и функции `q` / `logs` — `docs/claude/staging-aliases.sh`.
Выкатка на стенд: в `~/claudushka-test` `git fetch && git checkout --detach origin/feat/broadcast`, затем
`docker compose -f docker-compose.test.yml up -d --force-recreate claudushka-test` (новых обязательных переменных нет). **Бэкап БД стенда** перед началом.
Нужны: тестовая группа с недавней активностью, «мёртвая» группа (старая активность или забаненная), второй админ бота, аккаунт, заблокировавший бота.
Прод, dnd и `edge` не трогать.

| Шаг | Где | Что делаю | Ожидание |
|---|---|---|---|
| 1 | Сервер | `logs 80 \| grep -i Traceback`; `q "SELECT name FROM sqlite_master WHERE name LIKE 'broadcast%'"` | Нет Traceback; таблицы `broadcasts`, `broadcast_log` |
| 2 | Группа | `/broadcast` от админа в группе | «только из личного чата» |
| 3 | Личка, обычный участник | `/broadcast` | Тишина (не админ) |
| 4 | Личка, админ | `/broadcast` без ответа на сообщение | «ответь на него командой /broadcast» |
| 5 | Личка, админ | Написать «тест 1», ответить `/broadcast test` | Уходит только админам стенда; у второго админа копия без «переслано от»; отчёт запустившему |
| 6 | Личка, админ | Ответить на «тест 1» командой `/broadcast` | Предпросмотр «Уйдёт в N групп и M личек» + «Отправить»/«Отмена»; ничего не ушло. Числа сверить с БД (группы не забаненные, с активностью людей за 30 дн.) |
| 7 | Личка, админ | «Отмена» | «Рассылка отменена»; повторное нажатие — «устарел или уже обработан» |
| 8 | Личка, админ | Новое сообщение, `/broadcast`, «Отправить»; нажать «Отправить» ещё раз | Копия пришла в активную группу и личку; второе нажатие — отказ; в мёртвую/забаненную группу не пришла |
| 9 | Личка, админ | Отчёт | «отправлено X, заблокирован/выгнан Y, …, время Z с»; `q "SELECT status,COUNT(*) FROM broadcast_log WHERE broadcast_id=<id> GROUP BY 1"` совпадает |
| 10 | Личка, админ | **Стикер** → ответить `/broadcast test`, затем настоящая рассылка | Стикер пришёл стикером |
| 11 | Личка, админ | **Фото с подписью** → `/broadcast test` | Фото с подписью, форматирование сохранено |
| 12 | Группа | После шага 8 спросить бота «что за объявление?» | Бот понимает, что это служебное объявление; `q "SELECT content,is_bot FROM group_messages WHERE content LIKE '(служебное%' ORDER BY id DESC LIMIT 3"` |
| 13 | Личка | Среди получателей пользователь, заблокировавший бота | В отчёте «заблокирован/выгнан»; рассылка дошла до остальных |
| 14 | Личка, админ | `/broadcast`, «Отправить», сразу `/broadcast` ещё раз и `/broadcast stop` | «уже идёт»; после stop — отчёт «остановлена», `broadcasts.status='stopped'` |
| 15 | Личка, админ | `/broadcast resume` | Дошлёт только `pending`, без дублей у получивших |
| 16 | Сервер | Во время рассылки `docker restart claudushka-test`, затем `/broadcast resume` | Дошлёт оставшимся; получившие второй раз не получают |
| 17 | Личка, админ | `/broadcast all` | В предпросмотре число больше, чем в шаге 6 (без фильтра активности) |
