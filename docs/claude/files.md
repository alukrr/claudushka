# Файлы целиком (`[[FILE: имя]]`, v1.6.0)

Перед правкой `FILE_MARKER_RE`, `extract_files`, `_safe_filename`, `_file_sent_note`, `FILE_*` констант
и блока «ты умеешь присылать файлы» в `get_system_prompt` — читай этот файл.

Зачем: Telegram режет длинные сообщения, а в питоне важны отступы. По просьбе («пришли файлом», «весь
модуль») Клодушка оборачивает содержимое в `[[FILE: имя.py]]` … `[[/FILE]]` (каждый маркер на своей строке),
бот вырезает блок из текста и шлёт его документом (`reply_document`) ПОСЛЕ текстового ответа.

- Только текстовая ветка `handle_message` (как `[[DRAW]]`), не фото/документ/голос. Парсинг — после проверки
  пустого ответа, до `DRAW_MARKER_RE`; текст без файлов уходит как обычно.
- `extract_files`: ``` -ограждение вокруг содержимого, если модель его добавила, снимается; имя чистится
  `_safe_filename` (basename, `[\w.-]`, ≤80, нет точки → `.txt`); пустые блоки игнорируются.
- Лимиты: `FILE_MAX_PER_REPLY=3` (остальные вырезаются, не шлются), `FILE_MAX_BYTES=300_000` (больше — текст
  «слишком большой»).
- **Незакрытый блок** = ответ упёрся в max_tokens (`out_tokens(_model, 4096)` — видимый бюджет диалога):
  файл всё равно уходит, следом предупреждение «оборвался, файл неполный». Для больших файлов — просить
  частями. Поднимать лимит не стали: это деньги на каждый ответ, решение за Алексеем.
- **История / контекст:** в `conversations` и `group_messages` вместо блока пишется
  `(в чат отправлен файл имя, N строк; содержимое: <первые FILE_HISTORY_CHARS=3000 символов>…)`
  (`_file_sent_note`; `FILE_SENT_LABEL`). Это ограничение по размеру (инвариант CLAUDE.md) и одновременно
  чтобы «добавь функцию» не теряла контекст. System-prompt говорит, что пометка — не образец (тот же приём,
  что у `DRAW_SENT_LABEL`). Рост system-prompt — ~10 строк, статичен, кэш префикса не ломается (один раз
  при деплое).
- Стоимость: отдельного вызова нет, это те же выходные токены диалога, `usage_log` как обычно.
- Не сделано: файлы из команд, ответ на присланный файл правкой «в тот же файл», ZIP/бинарники,
  утечка маркера обычным текстом (fallback-регекса, как у DRAW, нет — не встречалась).
