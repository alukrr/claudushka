# Чек-лист стенда: ТЗ `feat/stars-topup` (пополнение баланса звёздами Telegram)

ТЗ — `docs/claude/tz-stars-topup.md`, устройство — `docs/claude/billing.md` → «Пополнение Stars», мини-приложение — `docs/claude/miniapp.md`. Места **TG-админ / TG-участник / Сервер**
и функции `q` / `logs` — `docs/claude/staging-aliases.sh`. **Выкатка — только `--force-recreate`** (новые переменные `.env.test`): в `~/claudushka-test`
`git fetch && git checkout feat/stars-topup && git pull`, в `.env.test` добавить `STARS_PACKS=1,5,10` (и при желании `STARS_USD_RATE`), затем
`docker compose -f docker-compose.test.yml up -d --force-recreate claudushka-test`. Юнит-тесты: `python -m pytest scripts/test_stars_topup.py scripts/test_stars_miniapp.py -q`.
Платить настоящими звёздами (1–10 ⭐) тестовому боту; **бэкап БД стенда** перед началом (`docs/claude/staging.md`). Прод, dnd и `edge` не трогать.

Нужны: тестовая группа стенда (платная или нет — проверить оба), аккаунты **П** (платит), **В** (второй участник группы), **С** (не в группе), админ бота, аккаунт с ≥ 10 ⭐.

| Шаг | Где | Что делаю | Ожидание |
|---|---|---|---|
| 1 | Сервер | `logs 80 \| grep -iE "Traceback\|miniapp"`; `q "SELECT name FROM sqlite_master WHERE name='star_payments'"` | Бот поднялся без Traceback; таблица `star_payments` создана |
| 2 | Личка, П | `/pay` | Сообщение с кнопками 1/5/10 ⭐ (подпись «≈ $X на баланс»), ссылки на `/pay help`, `/terms`, `/paysupport` |
| 3 | Личка, П | `/pay help`, `/terms`, `/paysupport` | Справка без `**`; условия; поддержка с пометкой «поддержка Telegram по покупкам в ботах не помогает» |
| 4 | Личка, П | Нажать пакет «1 ⭐» → оплатить | Пришёл счёт (XTR); после оплаты «✅ Зачислено $0.01 (1 ⭐). Баланс: …» **один раз**; админам — «⭐ Stars: …» с `charge_id` |
| 5 | Сервер | `q "SELECT * FROM star_payments"`, `q "SELECT * FROM chat_credits WHERE note LIKE 'stars:%'"` | Одна строка платежа (`status=paid`, `rate=0.01`), одна строка `chat_credits` `kind=topup` `note=stars:<charge_id>` `by_user=<П>`; баланс чата = сумме |
| 6 | Сервер | Повтор апдейта: перезапустить бот сразу после платежа, посмотреть `docker logs` на `successful_payment` | Второго зачисления нет, дубля в `star_payments` нет |
| 7 | Личка, П | Нажать пакет и в окне счёта отменить | Денег и записей нет; в `star_payments` без новых строк |
| 8 | Группа, П | `/pay` → «5 ⭐» → оплатить | Счёт в группе; «✅ Зачислено» — в группе; зачислено на баланс ГРУППЫ (`/cost` в группе от админа чата) |
| 9 | Группа, В (не платил) | Нажать кнопку пакета в сообщении П | Счёт приходит и ему (любой участник может платить); после оплаты — зачислено группе |
| 10 | Группа, не админ | `/topup` без аргументов; `/topup <id> <сумма>` | Оба открывают пакеты Stars (не молчат) |
| 11 | Приложение, П | Группа → «Пополнить баланс ⭐» → пакет → оплатить (**iOS, Android, Desktop** — отметить каждый) | Окно оплаты поверх приложения; статус `paid` → «Оплачено! Зачисляю…» → экран перечитан, баланс вырос; в личке с ботом пришло «✅ Зачислено», в ГРУППУ — «Баланс чата пополнен на … (от <имя>)» |
| 12 | Приложение, П | Экран «Расходы» (админ чата) → «Пополнить баланс ⭐» | Тот же экран пополнения |
| 13 | Приложение, С (не в группе) | Открыть `…?startapp=chat_n<id группы>` и/или запрос `POST /api/chats/<id>/topup` | 403 «Нет доступа к этому чату», ссылка не создаётся |
| 14 | Приложение, П | «Как купить звёзды из России» | Блок раскрывается, текст читаем, нет разметки `**` |
| 15 | Порог и бонус (П1) | Личка: пополнения $1.99 → не проверена; ещё $0.01 → проверена + бонус $2 (на стенде — `/topup`, затем Stars 200 ⭐ = ровно порог). Группа: $4.99 → нет; $5 → проверена + бонус $5. Два платежа по 100 ⭐ в личке | Порог по сумме в $: бонус на втором 100 ⭐; в «✅ Зачислено» строка «Чат проверен… стартовый бонус $2/$5»; `/verify` даёт те же $2/$5 |
| 15а | Возврат единственного платежа (П4) | Новая личка/группа, один платёж 200 ⭐ (личка) → бонус $2 → `/refund <id>` | Ответ: «Проверка снята, бонус отозван на $2.00»; `q "SELECT kind,amount,note FROM chat_credits WHERE chat_id=<id>"` — строка `bonus` `revoke:<charge_id>` −2; баланс 0 (не минус); чат снова непроверен |
| 15б | Возврат с потраченным бонусом | После платежа потратить часть (`/topup <id> -1.5`) → `/refund` | Отозван только остаток; баланс ≥ 0; повторная оплата довыдаёт бонус до $2, не больше |
| 15в | Возврат не единственного | Два платежа, вернуть первый | Проверка и бонус остаются |
| 16 | Тариф | Платёж в бесплатный чат (баланс 0) | Приходит «Платный режим включён…» (и НЕ приходит второе «Ура, баланс пополнен») |
| 17 | pre_checkout за 10 с | Во время долгого ответа модели в личке П (длинный запрос) нажать оплату пакета | Счёт оплачивается без ошибки по времени — `pre_checkout_query` не ждёт очередь чата |
| 18 | Бан | Забанить группу (`/ban <id>`) → попытка оплатить уже выставленный счёт | Telegram показывает отказ `pre_checkout` («Этот чат не может получать пополнения»), звёзды не списаны |
| 19 | Возврат | Админ: `/refund` | Список последних платежей с `charge_id` |
| 20 | Возврат | `/refund <charge_id платежа из шага 4>` | «↩️ Возвращено 1 ⭐…»; в Telegram звёзды вернулись плательщику (Настройки → Мои звёзды); если платёж был единственным — проверка снята, бонус отозван (шаг 15а); `star_payments.status=refunded`; в `chat_credits` строка `adjust` `note=stars-refund:<id>`; чату — сообщение о возврате |
| 21 | Возврат | Повторный `/refund` того же id | «Этот платёж уже возвращён.» |
| 22 | Возврат | Платёж, затем потратить/списать баланс ниже суммы платежа (`/topup <id> -<сумма>`), затем `/refund <id>` | «Не возвращаю: на балансе … а возврат …», звёзды не возвращены, платёж остался `paid` |
| 23 | `/cost` | Админ: общий `/cost` в личке и `/cost <chat_id>` | Есть строка «Пополнения Stars за неделю: N ⭐ / $X» (возвращённые не входят) |
| 24 | Регрессия | `/topup <chat_id> 2 тест` админом | Как раньше: ответ админу, чату — «Ура, баланс пополнен» или «Платный режим включён» |
| 25 | Курс | Сверка | `star_payments.usd` = `stars × STARS_USD_RATE` для каждой строки: `q "SELECT charge_id, stars, usd, rate FROM star_payments"` |
