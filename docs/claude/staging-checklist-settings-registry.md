# Чек-лист стенда: ТЗ `feat/settings-registry` (единый реестр настроек чата, рефакторинг, v2.4.1)

ТЗ — `docs/claude/tz-settings-registry.md`, устройство — `docs/claude/settings.md`. Поведение НЕ должно измениться: ответы те же, что в проде.
Автоматическое доказательство — `python -m pytest scripts/test_settings_registry.py -q` (720 случаев на нетронутом коде) +
`scripts/test_settings_units.py`. Здесь — живая проверка в Telegram: по одной команде каждого ключа в каждом положении. Места **TG-админ / TG-юзер /
Сервер** и функции `q` / `logs` — `docs/claude/staging-aliases.sh`. Новых файлов, таблиц и volume нет — выкатка `/update`.

Роли: **участник** (не админ чата и не админ бота), **админ группы** (админ чата, не админ бота), **админ бота**. Тарифы: **paid** (баланс > 0) и
**free** (`/topup` не делали). Для сравнения «как в проде» удобно держать открытыми два чата — стенд и боевой (или смотреть тексты в `tz-*`/доках).
