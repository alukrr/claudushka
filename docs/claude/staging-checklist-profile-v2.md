# Чек-лист стенда: `feat/profile-v2` (v2.20.0)

ТЗ — `docs/claude/tz-profile-v2.md`, описание — `docs/claude/profile.md` → «Профиль v2». Стенд — `docs/claude/staging.md` (тестовый бот; пул и ключ Google — реальные
деньги, но шаги 1–9 модель почти не вызывают). Есть изменение схемы (`profile_proposals.op`), поэтому стенд обязателен. На сервер — только с согласия Алексея
в текущей сессии. Имена людей из чатов в отчёты и в репозиторий не писать (репозиторий публичный): в SELECT'ах — только `user_id`/`id`.

## Подготовка
1. `git checkout feat/profile-v2 && git pull`; стенд пересобрать/перезапустить (новых mount'ов нет, но колонку добавит `init_db` при старте — нужен рестарт).
   В логе `claudushka-test`: «Application started», нет `Traceback`.
2. **Копия прод-БД для шагов 10–13** (не боевая!): `cp data/claudushka.db data/stage-profile.db`, на копии стенд и поднимается (или шаги ниже выполняются
   скриптом с `db.DB_PATH` на копию). Прод-БД не трогать.
3. Локально до стенда: `TELEGRAM_BOT_TOKEN=x ANTHROPIC_API_KEY=x python -m pytest scripts/test_profile_v2.py -q` — все зелёные.
