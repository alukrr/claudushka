# ТЗ: управляющие чата — права админа группы без админки в Telegram (`feat/chat-managers`)

Постановка Алексея 2026-11-01 (`docs/claude/roadmap-2026-11.md`): «можно вручную добавлять людей для управления ботом, хотя они и
не админы». Решения Алексея: такой человек в СВОЕЙ группе имеет права **как админ этого чата** (не как админ бота); добавляют и
убирают — **админы чата (настоящие, в Telegram) и админы бота**; сам управляющий других не добавляет.

**Зависимость:** `feat/settings-registry` в `main` (права на настройки идут через `can_change` с флагом `is_chat_admin`). Делать от
свежего `main` после его мержа. ТЗ для отдельной сессии: **сначала `CLAUDE.md` целиком**, затем `docs/claude/settings.md`,
`docs/claude/group-chat.md`, `.claude/rules/db.md`.

## Что сделать
1. **БД:** `CREATE TABLE IF NOT EXISTS chat_managers (chat_id INTEGER NOT NULL, user_id INTEGER NOT NULL, added_by INTEGER,
   added_at INTEGER, PRIMARY KEY (chat_id, user_id))`; функции `add_chat_manager`, `remove_chat_manager -> bool`,
   `is_chat_manager_db -> bool`, `list_chat_managers(chat_id) -> list[dict]`. В `.claude/rules/db.md` — строка со ссылкой на `group-chat.md`.
2. **`is_chat_admin` (bot.py) — единая точка**, через неё сейчас ходят `/ratelimit`, `/review_on|off`, реестр (`_check_change`),
   `/unignore` и т.д., поэтому управляющие получат права везде сразу:
   - админ бота → True (как сейчас);
   - `get_chat_member` (один запрос, как сейчас): `administrator`/`creator` → True;
   - статус `member`/`restricted` **и** строка в `chat_managers` → True. Вышел из группы или кикнут (`left`/`kicked`) → False, даже
     если строка есть (строку не удалять автоматически — вернётся в группу, права вернутся);
   - ошибка запроса → False (как сейчас).
   - Новая функция `is_real_chat_admin(context, chat_id, user_id)` — то же без `chat_managers` (админ бота или админ в Telegram). Только
     она — в командах выдачи прав (п.3), чтобы управляющий не мог добавлять других.
   - Проверить все вызовы `is_chat_admin` и по каждому записать в отчёте: управляющему это право положено? Ожидание — да везде
     (это «права админа чата»), кроме выдачи прав. Если где-то нет — спросить Алексея, не решать самой.
3. **Команды (только группы; в личке — «только для групп»):**
   - `/manager add` ответом на сообщение или `/manager add <user_id>`; `/manager rm` так же; `/managers` — список (имя по последней
     реплике в `group_messages`, uid, кто и когда добавил). Добавлять/убирать — `is_real_chat_admin`; смотреть список — `is_chat_admin`.
   - Админа бота и того, кто уже админ в Telegram, добавлять незачем — ответить «он и так админ», не писать строку. Бота — нельзя.
   - Ответы короткие: «Имя теперь управляет ботом в этом чате (как админ чата)», «Имя больше не управляет ботом в этом чате».
   - Регистрация в `main()` и в множестве известных команд (там, где `review_persona`, `autoignore`).
4. **Автоигнор:** управляющие НЕ освобождаются (освобождены только админы бота, как сейчас) — поведение не менять.
5. **Мини-приложение** (следующая ветка) получит это бесплатно: права там считаются тем же `is_chat_admin`.

## Не делать
- Не давать управляющим ничего из админки бота: деньги, баны, проверка, чужие чаты, `/update`, `/review` (разовый), `/hidden` и т.п.
  (они проверяют `is_admin`, не `is_chat_admin` — не трогать).
- Не менять `can_change` и тексты отказов: управляющий для него просто `is_chat_admin=True`.
- Не мержить, не ставить тег, не заходить на сервер.
