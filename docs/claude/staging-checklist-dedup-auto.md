# Чек-лист стенда: `feat/dedup-auto` (v2.19.0)

ТЗ — `docs/claude/tz-dedup-auto.md`. Стенд — `docs/claude/staging.md` (тестовый бот, пустая БД, тот же пул и ключ
Google — по центам реальных денег). На сервер — только с согласия Алексея в текущей сессии.

## Подготовка
1. На сервере: `git checkout feat/dedup-auto && git pull`, стенд пересобрать с `--force-recreate` (новый mount
   `dedup_memory.py`). В логе `claudushka-test` — «Application started», нет `Traceback`.
2. Наполнить память стенда: с двух аккаунтов в личке и в тестовой группе написать боту о себе 15–20 фраз с повторами
   («люблю котов», «у меня кот Барсик», «обожаю кошек»…), дождаться извлечения (`/memory`). Либо — если исполнитель
   сделал — скрипт-засев синтетических фактов в БД стенда (не в прод!).

## Шаги
| # | Действие | Ожидание |
|---|---|---|
| 1 | `/dedup_auto` | Режим `estimate`, время следующего прогона — понедельник 05:07 Berlin |
| 2 | `/dedup_auto estimate` | Список групп к проверке (10+ фактов), оценка $; в `usage_log` новых строк нет |
| 3 | `/dedup_auto run` → кнопка | Отчёт: было → стало, потрачено $, имя бэкапа; `/memory` — дубли слиты, смысл не потерян |
| 4 | `SELECT * FROM memory_dedup_state` | Строки обработанных групп, `checked_at` ≥ `created_at` слитых фактов |
| 5 | Сразу снова `/dedup_auto estimate` | Групп к проверке 0 (ничего нового) |
| 6 | Добавить 5+ новых фактов одному человеку, `/dedup_auto estimate` | Только его группа к проверке |
| 7 | `/cost` личного чата админа | Строки метки `memory_dedup`, сумма ≈ «потрачено» из отчёта |
| 8 | `/forget` у одного участника → `memory_dedup_state` | Его строк нет |
| 9 | `/dedup_auto off`, `/dedup_auto` | Режим `off`; недельная задача ничего не делает |
| 10 | (по возможности) Gemini пула недоступен | В логе `FALLBACK gemini-3.8-flash → google-direct/gemini-3.8-flash`, прогон дошёл; повторного выполнения bot.py нет |
